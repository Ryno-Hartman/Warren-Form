# Financial Consultation Form

A mobile-first static consultation form prepared for Netlify Forms.

## Preview locally

Open `index.html` directly, or serve this folder with any local static server. Local submissions show a preview success state without sending data.

## Publish on Netlify

Create a new Netlify site from this folder or repository. No build command is required and the publish directory is `.`. After the first deployment, submissions will appear under the site’s **Forms** area.

Before sharing the page publicly, replace the generic identity and confirm Warren’s business name, credentials, contact expectations, privacy policy, regulatory disclosures, and the currency ranges in the form.
